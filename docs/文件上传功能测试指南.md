### 2. 前端功能验证

#### 测试步骤

1. **启动前端服务**
   ```bash
   cd grt_testhub/frontend
   npm run dev
   ```

2. **打开场景编辑页面**
   - 访问：http://localhost:5173/api-testing/automation-scenarios
   - 选择一个现有场景或创建新场景

3. **添加接口步骤**
   - 点击"添加步骤"
   - 选择一个包含文件上传的接口（或创建新接口）

4. **编辑请求体**
   - 切换到"请求体"标签
   - 选择 `form-data` 类型

5. **添加文件字段**
   - 点击"添加行"
   - Key: 填写字段名（如 `avatar`）
   - Type: 选择 `file`
   - 点击"选择文件"按钮

6. **验证文件上传**
   - 选择一个测试文件（如 test.jpg）
   - 检查是否显示文件名和大小
   - 打开浏览器开发者工具，查看网络请求
   - 确认有 POST 请求到 `/api-testing/temp-files/upload/`
   - 确认返回数据包含 `file_path`

7. **保存场景步骤**
   - 点击"保存"按钮
   - 确认保存成功
   - 检查数据库中的 `override_body` 字段是否包含 `file_path`

8. **执行场景**
   - 点击"执行场景"按钮
   - 查看执行日志
   - 确认文件正确发送到目标服务器

9. **验证清理**
   - 执行完成后，检查临时目录
   - 确认文件已被清理（或手动调用清理 API）

## 三、常见问题排查

### 问题 1：文件上传失败

**症状**: 前端选择文件后报错

**排查步骤**:
1. 检查后端服务是否运行
2. 检查 API 路径是否正确
3. 检查认证 Token 是否有效
4. 检查文件大小是否超限
5. 检查 media 目录权限

**解决方案**:
```python
# 检查 settings.py
MEDIA_ROOT = os.path.join(BASE_DIR, 'media')
MEDIA_URL = '/media/'

# 确保 media 目录存在且有写权限
mkdir -p media/temp_files
chmod 755 media/temp_files
```

### 问题 2：执行时找不到文件

**症状**: 执行场景时报错"文件不存在"

**排查步骤**:
1. 检查 `file_path` 是否正确保存
2. 检查文件是否在临时目录中
3. 检查文件是否被提前清理
4. 检查 MEDIA_ROOT 配置

**解决方案**:
```python
# 检查 executor.py 中的文件路径处理
full_file_path = os.path.join(settings.MEDIA_ROOT, file_path)
print(f"文件路径: {full_file_path}")
print(f"文件是否存在: {os.path.exists(full_file_path)}")
```

### 问题 3：multipart 编码失败

**症状**: 请求发送失败或格式错误

**排查步骤**:
1. 检查 `requests_toolbelt` 是否安装
2. 检查文件内容是否正确读取
3. 检查 Content-Type 是否正确设置

**解决方案**:
```bash
# 安装依赖
pip install requests_toolbelt

# 检查 multipart 编码
from requests_toolbelt.multipart.encoder import MultipartEncoder
encoder = MultipartEncoder(fields=multipart_data)
print(f"Content-Type: {encoder.content_type}")
```

### 问题 4：前端不显示文件信息

**症状**: 选择文件后没有显示文件名

**排查步骤**:
1. 检查浏览器控制台是否有错误
2. 检查 API 返回数据格式
3. 检查 Vue 数据绑定是否正确

**解决方案**:
```javascript
// 检查 handleFileChange 方法
console.log('response data:', response.data)
console.log('rows value:', rows.value[index])

// 确保数据正确更新
rows.value[index].file_path = response.data.file_path
rows.value[index].value = response.data.file_name
updateValue()
```

## 七、集成测试脚本

### 自动化测试脚本

```python
# test_file_upload.py
import requests
import os

BASE_URL = "http://localhost:8000"
TOKEN = "your_token_here"

def test_temp_file_upload():
    """测试临时文件上传"""
    # 准备测试文件
    test_file_path = "/tmp/test.jpg"
    with open(test_file_path, 'wb') as f:
        f.write(b"test content")
    
    # 上传文件
    url = f"{BASE_URL}/api-testing/temp-files/upload/"
    headers = {"Authorization": f"Bearer {TOKEN}"}
    
    with open(test_file_path, 'rb') as f:
        files = {'file': f}
        data = {'scenario_id': '1'}
        response = requests.post(url, headers=headers, files=files, data=data)
    
    print(f"上传响应: {response.json()}")
    
    # 验证文件路径
    assert response.status_code == 200
    assert 'file_path' in response.json()
    
    file_path = response.json()['file_path']
    
    # 清理文件
    cleanup_url = f"{BASE_URL}/api-testing/temp-files/cleanup/"
    cleanup_data = {'scenario_id': '1'}
    response = requests.post(cleanup_url, headers=headers, json=cleanup_data)
    
    print(f"清理响应: {response.json()}")
    assert response.status_code == 200
    
    # 删除测试文件
    os.remove(test_file_path)
    
    print("✅ 文件上传测试通过")

if __name__ == "__main__":
    test_temp_file_upload()
```
