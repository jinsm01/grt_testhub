# 接口数据传递问题排查指南

## 问题描述

**症状**: 请求中包含了数据（如 kb_id），但响应提示说参数未传递

## 一、常见原因分析

### 1. 数据格式问题

#### ❌ 常见错误
- 请求体格式不正确（JSON vs form-data）
- 参数位置错误（query params vs body）
- 数据类型不匹配（string vs number）

#### ✅ 正确做法
- 确认 API 接受的数据格式
- 检查参数应该放在哪里（URL、Header、Body）
- 确保数据类型正确

### 2. 参数名称问题

#### ❌ 常见错误
- 参数名拼写错误
- 大小写不匹配
- 使用了错误的字段名

#### ✅ 正确做法
- 对照 API 文档确认参数名
- 检查前后端参数名是否一致
- 注意大小写敏感性

### 3. 数据传递路径问题

#### ❌ 常见错误
- 前端未正确发送数据
- 后端未正确接收数据
- 数据在中间环节丢失

#### ✅ 正确做法
- 检查前端网络请求
- 检查后端接收逻辑
- 添加日志追踪数据流

#### 检查参数获取方式

```python
# 常见的参数获取方式

# 1. URL 参数
```

## 三、常见问题解决

### 问题 1：form-data 格式数据未传递

**症状**: 请求 Payload 显示有数据，但后端接收不到

**排查**:
```python
# 检查前端是否正确编码
// form-data 格式
formData.append('kb_id', value);

# 检查后端是否正确解析
kb_id = request.POST.get('kb_id')  # 表单方式
kb_id = request.data.get('kb_id')  # DRF 方式
```

**解决**:
- 前端确保使用 FormData 对象
- 后端使用正确的获取方式

### 问题 2：JSON Body 数据未传递

**症状**: JSON 数据发送了，但后端解析不到

**排查**:
```python
# 检查 Content-Type
Content-Type: application/json

# 检查数据格式
{
  "kb_id": "value",  // 正确
  "kbId": "value"    // 错误（如果后端期望 kb_id）
}
```

**解决**:
- 确保 Content-Type 正确
- 确保 JSON 字段名与后端期望一致

### 问题 3：场景编排数据未传递

**症状**: 场景步骤配置了数据，但执行时未传递

**排查**:
```python
# 检查 override_body 数据格式
{
  "type": "form-data",  # 或 "json"
  "data": [
    {"key": "kb_id", "value": "xxx", "type": "string"}
  ]
}

# 检查 executor 是否正确处理
print(f"DEBUG - body: {request_data.get('body')}")
```

**解决**:
- 确保数据格式正确
- 确保 executor 正确解析和发送

```javascript
  kb_id: kb_id,
  type: typeof kb_id,
  value: kb_id
});
```

#### 后端验证
```python
# DRF Serializer 验证

    kb_id = serializers.CharField(required=True)
    
    def validate_kb_id(self, value):
        if not value:
            raise serializers.ValidationError("kb_id 不能为空")
        return value

# 视图验证
def your_view(request):
    kb_id = request.data.get('kb_id')
    if not kb_id:
        return Response({'error': '缺少 kb_id 参数'}, status=400)
```

