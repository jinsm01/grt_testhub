# 场景编排文件上传 - 快速开始指南

## 一、功能简介

场景编排现在支持**完整的文件上传功能**！

**解决的问题**:
- ❌ 之前：场景编排只能显示文件名，无法实际上传
- ✅ 现在：支持真实的文件上传和发送

**实现方案**:
- 编辑场景时上传到临时目录
- 执行时读取临时文件并发送
- 执行后自动清理临时文件

---

## 二、快速使用步骤

### 步骤 1：确保后端服务正常运行

```bash
# 启动 Django 服务
cd grt_testhub
python manage.py runserver

# 确认 API 可访问
curl http://localhost:8000/api-testing/temp-files/upload/
```

### 步骤 2：创建包含文件上传的场景

#### 方式 1：从 Apifox 导入
```
1. 导入 Apifox CLI JSON 文件
2. 自动识别包含文件的接口
3. 场景步骤自动包含文件配置
```

#### 方式 2：手动创建场景
```
1. 打开"自动化场景"页面
2. 点击"创建场景"
3. 添加接口步骤
4. 选择 form-data 类型
5. 添加 file 类型字段
```

### 步骤 3：编辑文件字段

```
1. 在 KeyValueEditor 中添加字段
2. Key: 输入字段名（如 "avatar"）
3. Type: 选择 "file"
4. 点击"选择文件"按钮
5. 选择本地文件（如 test.jpg）

→ 系统自动上传到临时目录
→ 显示文件名和大小
→ 保存 file_path 到数据
```

### 步骤 4：保存场景

```
1. 填写场景名称和描述
2. 点击"保存场景"
3. 确认保存成功
```

### 步骤 5：执行场景

```
1. 选择执行环境
2. 点击"执行场景"
3. 查看执行结果

→ 从临时目录读取文件
→ multipart/form-data 发送
→ 记录执行结果
→ 自动清理临时文件
```

## 三、使用示例

### 示例 1：上传用户头像

**场景**: 用户注册流程

**步骤 1**: 填写用户信息
```
POST /api/users/register
Content-Type: multipart/form-data

{
  "username": "testuser",
  "password": "password123",
  "avatar": <file>
}
```

**步骤 2**: 验证注册成功
```
GET /api/users/profile
Authorization: Bearer <token>

期望：返回用户信息，包含头像 URL
```

**配置方法**:
```
1. 创建场景"用户注册"
2. 添加步骤 1：填写用户信息
   - Body Type: form-data
   - 字段：
     - username (string): testuser
     - password (string): password123
     - avatar (file): 选择头像文件
3. 添加步骤 2：验证注册
   - 使用变量引用：{{$.1.response.body.token}}
```

### 示例 2：批量上传文件

**场景**: 文件批量导入

**接口**: POST /api/files/batch-upload

**配置**:
```
form-data:
- file1 (file): document1.pdf
- file2 (file): document2.pdf
- file3 (file): document3.pdf
- description (string): 批量上传测试文件
```

## 四、常见问题解答

### Q1: 文件上传后保存在哪里？

**A**: 保存在临时目录：
```
media/temp_files/scenario_<id>/<uuid>_<filename>
```

- 按场景 ID 组织
- UUID 前缀避免冲突
- 24 小时后自动清理

### Q2: 执行时找不到文件怎么办？

**A**: 检查以下几点：
1. 文件是否成功上传（查看返回的 file_path）
2. 临时文件是否存在（ls media/temp_files/）
3. MEDIA_ROOT 配置是否正确
4. 文件是否被提前清理

### Q3: 支持哪些文件类型？

**A**: 默认支持所有类型，建议：
- 图片：jpg, png, gif
- 文档：pdf, doc, docx
- 数据：json, xml, csv

### Q4: 文件大小有限制吗？

**A**: 默认无限制，建议：
- 单文件：< 10MB
- 总大小：< 100MB
- 可在 settings.py 中配置限制

### Q5: 执行后文件会清理吗？

**A**: 会自动清理：
- 执行完成后立即清理
- 或 24 小时后自动过期清理
- 可手动调用清理 API

### Q6: 不影响原有功能吗？

**A**: 完全不影响：
- ✅ 单接口文件上传正常
- ✅ JSON/Raw 格式正常
- ✅ Apifox 导入正常
- ✅ 其他功能正常

## 五、进阶使用

### 1. 跨步骤文件引用

场景：第 1 步上传文件，第 2 步使用返回的文件 ID

```
步骤 1: 上传文件
POST /api/files/upload
form-data:
- file (file): test.jpg

提取变量：
- file_id: $.response.body.id

步骤 2: 使用文件
POST /api/documents/create
JSON:
{
  "title": "文档标题",
  "file_id": "{{file_id}}"
}
```

### 2. 文件 Mock 数据

不实际上传文件，只 Mock 文件名：

```
form-data:
- filename (string): test.jpg
- filesize (number): 102400
- filetype (string): image/jpeg
```

### 3. 批量场景执行

多个场景共享文件：

```
场景 1: 准备文件
步骤 1: 上传文件，保存 file_id

场景 2: 使用文件
引用场景 1，继承变量 file_id
使用 file_id 进行操作
```
