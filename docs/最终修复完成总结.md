## 问题回顾

### 你的描述

- **单接口执行**: 正常工作 ✅
- **场景编排执行**: 报错"参数未传递" ❌
- **单接口没有 enabled 复选框** ← 关键线索

### 问题根源

**场景编排引入了 enabled 字段检查，而单接口没有这个概念**

```python
# 场景编排原有逻辑（有问题）
if item.get('enabled'):  # 检查 enabled
    multipart_data[key] = value
else:
    # enabled 缺失或为 false，字段被过滤掉 ← 问题！
    pass
```

**单接口执行逻辑**（正常）：
```python
# 单接口执行逻辑
# 不检查 enabled，所有字段都发送 ← 正确！
multipart_data[key] = value
```

## 最终修复

### ✅ 完全移除 enabled 检查

**修改后的逻辑**:
```python
# ✨✨✨ 不再检查 enabled，直接处理所有字段 ✨✨✨
multipart_data[key] = value
print(f"[DEBUG] 添加字段: {key}={value} (不检查 enabled)")
```

**效果**:
- ✅ 与单接口执行逻辑完全一致
- ✅ 所有字段都会被发送
