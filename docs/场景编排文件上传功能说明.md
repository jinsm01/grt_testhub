# 场景编排文件上传功能实现说明

## 功能概述

本次改进实现了自动化测试场景编排中的**完整文件上传支持**，采用"临时文件存储"方案：

1. 编辑场景时上传文件到临时目录
2. 保存文件路径到数据库（JSONField）
3. 执行场景时读取临时文件并发送
4. 执行完成后自动清理临时文件

---

## 一、后端实现

### 1. 临时文件上传 API

**文件位置**: `apps/api_testing/views_scenario.py`

**新增 API 接口**:

#### (1) 上传临时文件
```
POST /api-testing/temp-files/upload/
```

**请求参数**:
- `file`: 文件对象（multipart/form-data）
- `scenario_id`: 场景ID（可选，用于组织文件）

**返回数据**:
```json
{
  "file_id": "uuid",
  "file_path": "temp_files/scenario_123/a1b2c3d4_photo.jpg",
  "file_name": "photo.jpg",
  "file_size": 102400,
  "content_type": "image/jpeg",
  "expires_at": "2024-01-01T00:00:00Z",
  "upload_time": "2024-01-01T00:00:00Z"
}
```

#### (2) 清理临时文件
```
POST /api-testing/temp-files/cleanup/
```

**请求参数**:
```json
{
  "file_paths": ["path1", "path2"],  // 清理指定文件
  "scenario_id": 123,                // 清理整个场景的文件
  "older_than_hours": 24             // 清理超过24小时的文件
}
```

#### (3) 获取文件信息
```
GET /api-testing/temp-files/info/?file_path=<path>
```

### 2. 执行引擎改进

**文件位置**: `apps/api_testing/scenario_engine/executor.py`

**改进内容**:

原有的 `_send_request` 方法已支持：
- ✅ 识别 `body['type'] == 'form-data'`
- ✅ 从 `item['file_path']` 读取临时文件
- ✅ 使用 `MultipartEncoder` 编码 multipart 数据
- ✅ 正确发送文件内容到目标服务器

**关键代码片段**:
```python
if body_type == 'form-data':
    multipart_data = {}
    has_files = False
    
    for item in body_data:
        if item['type'] == 'file':
            file_path = item.get('file_path')
            if file_path:
                # 从临时目录读取文件
                full_file_path = os.path.join(settings.MEDIA_ROOT, file_path)
                if os.path.exists(full_file_path):
                    with open(full_file_path, 'rb') as f:
                        file_content = f.read()
                    
                    # 添加到 multipart 数据
                    multipart_data[item['key']] = (
                        item['value'],  # 原始文件名
                        file_content,
                        item.get('content_type', 'application/octet-stream')
                    )
                    has_files = True
    
    if has_files:
        encoder = MultipartEncoder(fields=multipart_data)
        headers_dict['Content-Type'] = encoder.content_type
        request_kwargs['data'] = encoder
```

```javascript
const handleFileChange = async (index, uploadFile) => {
  // 创建 FormData 上传文件
  const formData = new FormData()
  formData.append('file', uploadFile.raw)
  if (currentScenarioId.value) {
    formData.append('scenario_id', currentScenarioId.value)
  }
  
  // 上传文件到临时目录
  const response = await axios.post('/api-testing/temp-files/upload/', formData)
  
  // ✨ 保存返回的文件信息
  rows.value[index].file_path = response.data.file_path  // 关键字段
  rows.value[index].value = response.data.file_name
  rows.value[index].file_size = response.data.file_size
  rows.value[index].content_type = response.data.content_type
  
  // 更新父组件数据
  updateValue()
}
```

## 四、临时文件管理

### 1. 文件存储结构

```
MEDIA_ROOT/
└── temp_files/
    ├── scenario_123/              # 按场景ID组织
    │   ├── a1b2c3d4_photo.jpg     # UUID前缀避免冲突
    │   └ e5f6g7h8_document.pdf
    ├── scenario_456/
    │   └── i9j0k1l2_data.json
    └── (自动清理过期文件)
```

### 2. 文件生命周期

```
上传 → 24小时内有效 → 执行场景时读取 → 执行完成后清理
```

### 3. 自动清理机制

**清理触发条件**:
1. 执行完成后调用 `cleanup_temp_files` API
2. 文件超过 24 小时自动过期
3. 手动调用清理 API

## 五、使用流程

### 1. 编辑场景时上传文件

```
1. 打开场景详情页
2. 选择 form-data 类型
3. 添加 file 类型字段
4. 点击"选择文件"按钮
5. 选择本地文件
   → 自动上传到临时目录
   → 返回 file_path
   → 保存到场景步骤数据
```

### 2. 执行场景时发送文件

```
1. 执行引擎读取场景步骤
2. 解析 form-data 数据
3. 检查是否有 file_path 字段
4. 从临时目录读取文件内容
5. 使用 MultipartEncoder 编码
6. 发送 multipart/form-data 请求
7. 记录执行结果
8. 自动清理临时文件
```

## 七、注意事项

### 1. 文件大小限制

建议限制文件大小：
- 默认: 10MB
- 可在 `settings.py` 中配置

### 2. 文件类型限制

建议限制文件类型：
- 图片: jpg, png, gif
- 文档: pdf, doc, docx
- 数据: json, xml, csv

### 3. 安全考虑

- 临时文件目录不应对外暴露
- 文件路径使用 UUID 避免冲突
- 定期清理过期文件
- 检查文件类型防止恶意上传

### 4. 性能考虑

- 大文件上传可能影响性能
- 多文件上传考虑并发限制
- 临时文件清理避免磁盘占用
